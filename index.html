03. Método 1 (Apuntes de Clase)

Eliminación de Gauss (Método Simple)

Muestra los resultados en una matriz triangular. Procedimiento paso a paso según los apuntes de clase (Pasos 1 al 8):

1
Paso 1: Ordenar Ec ①, ②, ③
2
Paso 2: Normalizar Ec 1 Dividir entre a₁₁
3-4
Pasos 3-4: Eliminar x₁ En Ec ② y Ec ③
5-6
Pasos 5-6: Eliminar x₂ Despejar x₃
7-8
Pasos 7-8: Sustitución Hallar x₂ y x₁
Paso 1
Ordenar las ecuaciones según el coeficiente de la primera incógnita
①   0.52 x₁ + 0.20 x₂ + 0.25 x₃ = 4800
②   0.30 x₁ + 0.50 x₂ + 0.20 x₃ = 5810
③   0.18 x₁ + 0.30 x₂ + 0.55 x₃ = 5690
Paso 2
Normalizar la primera ecuación dividiendo entre el coeficiente de su primera incógnita (0.52)
(0.52 x₁ + 0.20 x₂ + 0.25 x₃ = 4800) / 0.52
x₁ + 0.384615 x₂ + 0.480769 x₃ = 9230.7692   [Primera ec normalizada]
Paso 3
Restar la segunda ecuación con la primera normalizada para eliminar x₁
   0.30 x₁ + 0.500000 x₂ + 0.200000 x₃ = 5810.0000
- 0.30 (x₁ + 0.384615 x₂ + 0.480769 x₃ = 9230.7692)
-------------------------------------------------------------
   0 x₁ + 0.384615 x₂ + 0.055769 x₃ = 3040.7692   [Segunda ecuación más reciente]
Paso 4
Restar la tercera ecuación con la primera normalizada para eliminar x₁
   0.18 x₁ + 0.300000 x₂ + 0.550000 x₃ = 5690.0000
- 0.18 (x₁ + 0.384615 x₂ + 0.480769 x₃ = 9230.7692)
-------------------------------------------------------------
   0 x₁ + 0.230769 x₂ + 0.463462 x₃ = 4028.4615   [Tercera ecuación más reciente]
Nuevo sistema de ecuaciones:
① x₁ + 0.384615 x₂ + 0.480769 x₃ = 9230.7692
② 0 x₁ + 0.384615 x₂ + 0.055769 x₃ = 3040.7692
③ 0 x₁ + 0.230769 x₂ + 0.463462 x₃ = 4028.4615
Paso 5
Normalizar la segunda ecuación más reciente (el coeficiente ahora sería el de x₂, dividiendo entre 0.384615)
(0.384615 x₂ + 0.055769 x₃ = 3040.7692) / 0.384615
0 x₁ + x₂ + 0.145000 x₃ = 7906.0000   [Segunda ec normalizada]
Paso 6
Restar la tercera ecuación más reciente menos la segunda ecuación normalizada con el propósito de eliminar x₂, obteniendo x₃
   0.230769 x₂ + 0.463462 x₃ = 4028.4615
- 0.230769 (x₂ + 0.145000 x₃ = 7906.0000)
-------------------------------------------------------------
   0 x₂ + 0.430000 x₃ = 2204.0000
Despejando x₃:   x₃ = 2204.0000 / 0.430000 = 5,125.5814 m³
Paso 7
Reemplazar x₃ en la segunda ecuación más reciente para encontrar x₂
x₂ + 0.145000 (5125.5814) = 7906.0000
x₂ + 743.2093 = 7906.0000
x₂ = 7906.0000 - 743.2093 = 7,162.7907 m³
Paso 8
Reemplazar x₂ y x₃ en la primera ecuación normalizada para encontrar x₁ (obteniendo los 3 valores)
x₁ + 0.384615 (7162.7907) + 0.480769 (5125.5814) = 9230.7692
x₁ + 2754.9195 + 2464.2185 = 9230.7692
x₁ = 9230.7692 - 5219.1380 = 4,011.6312 m³ (≈ 4,011.6279 m³)

04. Método 2 (Apuntes de Clase)

Método Gauss Jordan

Se trabaja con una matriz identidad para encontrar las soluciones. Pasos a seguir en el método (Pasos 1 al 10):

1-2
Pivote 1 Norm F1
3-4
Eliminar x₁ En F2 y F3
5-7
Pivote 2 Norm F2 y Elim F1, F3
8-10
Pivote 3 Norm F3 y Elim F1, F2
Matriz Identidad Solución directa [I | x]
Paso 1
Expresar los coeficientes como una matriz aumentada
[ 0.52   0.20   0.25 | 4800 ]   ①
[ 0.30   0.50   0.20 | 5810 ]   ②
[ 0.18   0.30   0.55 | 5690 ]   ③
Paso 2
Normalizar la primera ecuación dividiendo Fila 1 entre 0.52
[ 1.000000   0.384615   0.480769 | 9230.7692 ]   [Primera Normalizada]
Paso 3
Eliminar la segunda ecuación con la primera ecuación normalizada para eliminar x₁
Fila 2 = Fila 2 - 0.30 × Fila 1_norm
[ 0.000000   0.384615   0.055769 | 3040.7692 ]   [Segunda ec]
Paso 4
Eliminar la tercera ecuación con la primera ecuación normalizada para eliminar x₁
Fila 3 = Fila 3 - 0.18 × Fila 1_norm
[ 0.000000   0.230769   0.463462 | 4028.4615 ]   [Tercera ec]
Paso 5
Normalizar la segunda ecuación dividiendo Fila 2 entre 0.384615
[ 0.000000   1.000000   0.145000 | 7906.0000 ]   [Segunda Normalizada]
Paso 6
Eliminar x₂ de la primera ecuación con la segunda ecuación normalizada
Fila 1 = Fila 1 - 0.384615 × Fila 2_norm
Coeficiente x₃: 0.480769 - 0.384615 × 0.145000 = 0.425000
Término independiente: 9230.7692 - 0.384615 × 7906.0000 = 6190.0000
[ 1.000000   0.000000   0.425000 | 6190.0000 ]   [Primera ec]
Paso 7
Eliminar x₂ de la tercera ecuación con la segunda ecuación normalizada
Fila 3 = Fila 3 - 0.230769 × Fila 2_norm
Coeficiente x₃: 0.463462 - 0.230769 × 0.145000 = 0.430000
Término independiente: 4028.4615 - 0.230769 × 7906.0000 = 2204.0000
[ 0.000000   0.000000   0.430000 | 2204.0000 ]   [Tercera ec]
Paso 8
Normalizar la tercera ecuación más reciente dividiendo Fila 3 entre 0.430000
2204.0000 / 0.430000 = 5125.5814
[ 0.000000   0.000000   1.000000 | 5125.5814 ]   [Tercera Normalizada]
Paso 9
Eliminar x₃ de la primera ecuación con la tercera ecuación normalizada
Fila 1 = Fila 1 - 0.425000 × Fila 3_norm
Término independiente: 6190.0000 - 0.425000 × 5125.5814 = 4011.6279

Eliminar x₃ de la segunda ecuación con la tercera normalizada (obteniendo la Matriz Identidad)

Término independiente: 7906.0000 - 0.145000 × 5125.5814 = 7162.7907

05. Método 3 (Apuntes de Clase)

Gauss Seidel

En los dos primeros métodos el error se trabaja a medida de un error normalizado. En Gauss Seidel sí se utilizará la fórmula de error: Ea = |(Va - Vant) / Va| * 100. Pasos a seguir en el método (Pasos 1 al 9):

Paso 1
Ordenar la ecuación y verificar la diagonal principal dominante
0.52 x₁ + 0.20 x₂ + 0.25 x₃ = 4800    |0.52| > |0.20| + |0.25| = 0.45 [Dominante]
0.30 x₁ + 0.50 x₂ + 0.20 x₃ = 5810    |0.50| = |0.30| + |0.20| = 0.50 [Dominante débil]
0.18 x₁ + 0.30 x₂ + 0.55 x₃ = 5690    |0.55| > |0.18| + |0.30| = 0.48 [Dominante]
Paso 2
Despejar X₁ de la primera ecuación
X₁ = (4800 - 0.20 X₂ - 0.25 X₃) / 0.52   (I)
Paso 3
Despejar X₂ de la segunda ecuación
X₂ = (5810 - 0.30 X₁ - 0.20 X₃) / 0.50   (II)
Paso 4
Despejar X₃ de la tercera ecuación
X₃ = (5690 - 0.18 X₁ - 0.30 X₂) / 0.55   (III)
Paso 5
Asumir que X₂ y X₃ = 0 en la primera ecuación (Iteración 1)
X₁ = (4800 - 0.20(0) - 0.25(0)) / 0.52 = 4800 / 0.52 = 9,230.7692
Paso 6
Reemplazar X₁ en la segunda ecuación y asumir que X₃ = 0
X₂ = (5810 - 0.30(9230.7692) - 0.20(0)) / 0.50 = (5810 - 2769.2308) / 0.50 = 6,081.5385
Paso 7
Reemplazar X₁ y X₂ en la tercera ecuación
X₃ = (5690 - 0.18(9230.7692) - 0.30(6081.5385)) / 0.55
X₃ = (5690 - 1661.5385 - 1824.4615) / 0.55 = 2204.0 / 0.55 = 4,007.2727
Paso 8
Reemplazar X₁, X₂ y X₃ en las ecuaciones nuevamente (Iteración 2)
X₁ = [4800 - 0.20(6081.5385) - 0.25(4007.2727)] / 0.52 = 2581.8741 / 0.52 = 4,965.1425
X₂ = [5810 - 0.30(4965.1425) - 0.20(4007.2727)] / 0.50 = 3519.0027 / 0.50 = 7,038.0054
X₃ = [5690 - 0.18(4965.1425) - 0.30(7038.0054)] / 0.55 = 2684.8727 / 0.55 = 4,881.5868
Paso 9
Verificar el error en cada incógnita (Ea = |(Va - Vant) / Va| * 100)
Ea(x₁) = |(4965.1425 - 9230.7692) / 4965.1425| × 100% = 85.91%
Ea(x₂) = |(7038.0054 - 6081.5385) / 7038.0054| × 100% = 13.59%
Ea(x₃) = |(4881.5868 - 4007.2727) / 4881.5868| × 100% = 17.91%
"Como Ea > Es (5%), entonces debemos iterar de nuevo. Pero empezamos directo en el paso 8..."
